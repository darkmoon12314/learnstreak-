# Edusense AI - Learn Smarter, Not Harder

An advanced web-based learning platform featuring AI tutoring, streak tracking, gamification, and automated certificate generation.

## 🌟 Features

### Core Features
- **🎓 Structured Courses**: Python, Cybersecurity, AI, Web Development, Computer Networking
- **🔥 Daily Streak Tracking**: Maintain learning consistency with streak rewards
- **🤖 AI Tutor Integration**: Get instant help using Groq AI (Llama 3.3)
- **🏆 Gamification**: XP points, badges, and leaderboards
- **📜 Auto Certificate Generation**: PDF certificates for completed courses
- **📊 Progress Tracking**: Monitor your learning journey
- **🎯 Quiz System**: Test knowledge with interactive quizzes

### Advanced Features
- **Firebase Realtime Database**: User data persistence
- **Firebase Authentication**: Secure login/signup
- **AI Recommendations**: Smart course suggestions
- **Neon Blue Jarvis UI**: Futuristic, engaging interface
- **Responsive Design**: Works on all devices

## 🎨 UI Design

- **Theme**: Neon Blue Jarvis-style futuristic interface
- **Colors**: 
  - Primary: `#00E5FF` (Cyan)
  - Secondary: `#007BFF` (Blue)
  - Background: `#0A0F24` (Dark Navy)
  - Accent: `#00F0FF` (Bright Cyan)
- **Fonts**: Orbitron (headings), Poppins (body)

## 🎮 Gamification System

### XP Points
- Lesson completed: +10 XP
- Quiz passed: +20 XP
- Course completed: +100 XP

### Badges
- 🥉 Bronze Streak (3 days)
- 🥈 Silver Streak (7 days)
- 🥇 Gold Streak (30 days)
- 👑 Legend Streak (100 days)
- ⚡ Fast Learner (5 courses)
- 🎯 Quiz Master (20 quizzes)
- 💎 Consistency King (500 XP)
- 🤖 AI Explorer (Complete AI course)

## 🔧 Tech Stack

- **Frontend**: React 18, TypeScript
- **Routing**: React Router v7
- **Styling**: Tailwind CSS v4
- **Animations**: Motion (Framer Motion)
- **Database**: Firebase Realtime Database
- **Auth**: Firebase Authentication
- **AI**: Groq API (Llama 3.3)
- **PDF**: jsPDF
- **Icons**: Lucide React
- **Notifications**: Sonner

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- Firebase account
- Groq API key

### Configuration

The project is pre-configured with:
- Firebase config (in `/src/app/config/firebase.ts`)
- Groq API key (in `/src/app/config/groq.ts`)

### Installation

```bash
npm install
npm run dev
```

## 🔐 Security Notes

⚠️ **Important**: API keys are exposed in the client code for demo purposes. In production:
- Move API calls to a backend server
- Use environment variables
- Implement proper API key management
- Never expose sensitive credentials in client code
